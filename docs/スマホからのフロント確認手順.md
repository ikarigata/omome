# スマホからフロントを確認する手順（MSW + Tailscale）

ヘッドレスな自宅開発サーバーの **devcontainer 内**で vite dev を動かし、**スマホの実機**から見た目を確認するための手順。MSW（API モック）+ 認証バイパスで、バックエンド/Cognito 不要で全画面を確認できる。

## なぜこの構成なのか（前提）

- 開発サーバーは GUI なし。PC からは VS Code Remote-SSH / 素の ssh で入る。アプリは devcontainer 内で動く。
- **MSW はブラウザの Service Worker で動く**。Service Worker は **セキュアコンテキスト（HTTPS か `localhost`）でしか登録できない**。
  - PC は SSH ポートフォワードで `http://localhost:5173` になるので OK。
  - スマホで開発サーバーの IP に HTTP 直アクセスすると localhost でも HTTPS でもない → **SW が登録されず MSW が効かない**。
- そこで **Tailscale serve で HTTPS 配信**する。`*.ts.net` は実物の証明書付き = セキュアコンテキスト → SW が動く。
- `tailscale serve` は**リバースプロキシ**なので、アプリ（コンテナ内 vite）と同じ場所で動く必要はない。ホストからコンテナの 5173 に届きさえすれば中継できる。

## 経路

```
[スマホ]
   │ HTTPS (tailnet)
   ▼
[ホスト] tailscale serve  ← 中継のみ
   │ HTTP localhost:5173
   ▼ (docker のポート公開)
[コンテナ] vite dev (host:true, allowedHosts:true)
```

## 事前設定（コミット済み・初回のみ意識）

以下はリポジトリに反映済み。

- `frontend/vite.config.ts` の `server`:
  - `host: true` … 0.0.0.0 バインド（コンテナ外から到達できるように）
  - `port: 5173`
  - `allowedHosts: true` … `*.ts.net` 経由を許可（未設定だと Vite が "Blocked request. This host is not allowed." で弾く）
- `.devcontainer/docker-compose.yml` の `app` サービスに `ports: ["5173:5173"]` … コンテナの 5173 をホストの `localhost:5173` に公開。
  - **この `ports` 追加を反映するにはコンテナの再作成が必要**（VS Code: "Dev Containers: Rebuild Container"）。

## 毎回の手順

1. **（初回 / compose 変更後のみ）** VS Code でコマンドパレット → `Dev Containers: Rebuild Container`
2. **コンテナ内**で開発サーバーを起動
   ```bash
   VITE_DEV_BYPASS_AUTH=true npm run dev:frontend
   ```
   - `VITE_DEV_BYPASS_AUTH=true` … ログイン不要・MSW でダミーデータ表示。本番ビルドでは絶対に付けない。
3. **ホスト側**（コンテナの外、tailscale が入っているマシン）で公開
   ```bash
   tailscale serve --bg --https=443 localhost:5173
   ```
4. スマホのブラウザで開く
   ```
   https://<ホスト名>.<tailnet>.ts.net
   ```
   - ホスト名は `tailscale status` で確認できる。

## 運用コマンド（ホスト側）

```bash
tailscale serve status              # 現在の公開設定を確認
tailscale serve --https=443 off     # 公開を停止
```

## トラブルシュート

- **スマホで画面が壊れる / API が空振り**
  → HTTP でアクセスしていないか確認。必ず `https://...ts.net`。Service Worker は HTTPS でないと登録されない。
- **Vite が "Blocked request. This host is not allowed."**
  → `vite.config.ts` の `allowedHosts` を確認（`true` か、対象の `*.ts.net` を列挙）。
- **ホストから `localhost:5173` に繋がらない**
  → `docker-compose.yml` の `ports: ["5173:5173"]` が反映されているか（= Rebuild 済みか）。`docker compose ps` でポート公開を確認。
  → vite が `host: true` で起動しているか（localhost バインドだとコンテナ外から届かない）。
- **コンテナ再作成後に繋がらない**
  → `localhost:5173` publish 方式なのでコンテナ IP 変更の影響は受けない。vite の起動と tailscale serve の再確認を。

## PC から見るだけのとき（参考）

スマホ不要なら Tailscale は不要。VS Code Remote-SSH なら「ポート」パネルの `5173` を開くだけ（`localhost` 扱いで MSW もそのまま動く）。素の ssh なら `ssh -L 5173:localhost:5173 <host>`。
